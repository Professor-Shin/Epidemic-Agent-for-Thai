คลิกที่จุดในแผนภาพ หรือคลิกแถวในบันทึกการตัดสินใจ เพื่อดูข้อความจริงที่ระบบประกอบขึ้นส่งให้โมเดล

ระบบนี้ทำงานอย่างไร

ภาพรวม: สองชั้นที่ป้อนกันไปกลับ

ตัวแบบระบาดวิทยาทั่วไปกำหนด “พฤติกรรมคน” ด้วยสมการตายตัว แต่โปรเจกต์นี้ให้ โมเดลภาษา (Gemini ผ่าน Google ADK) สวมบทบาทเป็นชาวเมืองแต่ละคน แล้ว ตัดสินใจเองทุกวัน ว่าจะออกไปทำงานหรืออยู่บ้าน

  • ชั้นบน — Generative Agent: ตัวตน + บุคลิก + อาการ + ข่าว → LLM → JSON {"decision","reason"}
  • ชั้นล่าง — Agent-Based Model: เฉพาะคนที่ออกจากบ้านเท่านั้นที่จะพบปะกันและแพร่เชื้อได้
  • ป้อนกลับ: ผู้ติดเชื้อรายใหม่ → กลายเป็น “ข่าวเมื่อวาน” → เปลี่ยนการตัดสินใจของวันถัดไป
หัวใจของงานคือ วงป้อนกลับ นี้ — โรคเปลี่ยนพฤติกรรม แล้วพฤติกรรมย้อนกลับไปเปลี่ยนเส้นทางของโรค

ลูปหนึ่งวัน (src/runner.py → run())

ขั้นสิ่งที่เกิดขึ้น
1คำนวณ case_pct จากคนที่เข้าวันที่ 4 ของโรคเมื่อวาน แล้วยิง prompt ถาม LLM พร้อมกันทุกคน ด้วย asyncio.gather
2คนที่ตอบ “go” เท่านั้นเข้าเครือข่ายสัมผัส แต่ละคนสุ่มคู่ contact_rate คน เก็บเป็นเส้นเชื่อมแบบไม่ซ้ำ
3เส้นที่ปลายหนึ่งติดเชื้อ + อีกปลายยังไม่เคยติด → ทอยความน่าจะเป็น infectivity
4เดินนาฬิกาโรคของทุกคน คนที่เกิน 6 วันกลายเป็น “หายแล้ว” แล้วบันทึกสถิติของวัน

ถ้าไม่เหลือผู้ติดเชื้อเลย ระบบจะหยุดก่อนครบจำนวนวัน

เงื่อนไขการทดลอง 3 แบบ

เงื่อนไขข้อมูลที่ agent ได้รับ
baseชื่อ อายุ บุคลิก Big Five และเหตุผลที่ต้องทำงาน — ไม่รู้ว่าตัวเองป่วย ไม่รู้ว่ามีโรคระบาด
selfข้างต้น + อาการของตัวเองวันนี้
fullข้างต้น + ข่าวหนังสือพิมพ์ ที่บอก % ผู้ติดเชื้อรายใหม่เมื่อวาน

ลองสลับเงื่อนไขแล้วกดเริ่มใหม่ จะเห็นว่ายิ่งให้ข้อมูลมาก ยอดผู้ติดเชื้อยิ่งแบนลง เพราะ agent เลือกกักตัวเอง

ไทม์ไลน์ของโรค (src/disease.py)

วันที่ติดเชื้ออาการแพร่เชื้อได้?
0ปกติ (เพิ่งรับเชื้อ)ไม่ได้
1–2ปกติ — ไม่รู้ตัวได้
3ไอเล็กน้อยได้
4–5ไข้ + ไอได้
6ไอเล็กน้อยได้
7+หายและมีภูมิคุ้มกันไม่ได้

ช่วงวันที่ 1–2 คือจุดอันตราย: แพร่เชื้อได้แต่ยังไม่มีอาการ agent จึงยังตัดสินใจออกไปทำงานตามปกติ

โครงสร้างไฟล์

main.pyรับ argument จากบรรทัดคำสั่ง และสั่งรันทีละเงื่อนไข
src/config.pyค่าตั้งต้นทั้งหมดของการรันหนึ่งครั้ง
src/traits.pyสุ่มชื่อ อายุ 18–64 และบุคลิก Big Five (ขั้วบวก/ลบ อย่างละ 50%)
src/person.pyสถานะของคนหนึ่งคน + คำนวณอาการจาก infection_day
src/agent.pyประกอบ prompt เรียก LlmAgent และแปลง JSON ที่ตอบกลับเป็น Decision
src/world.pyสร้างเครือข่ายการสัมผัสและคำนวณการติดเชื้อรายใหม่
src/runner.pyลูปหลักรายวัน + เขียนผลลง summary_*.csv และ detail_*.json
plot_results.pyอ่าน CSV มาวาดกราฟเปรียบเทียบเงื่อนไข

วิธีรันของจริง

# ทดสอบแบบไม่เรียก LLM (ใช้ MockDecisionAgent)
python main.py --mock --population 20 --days 30

# รันจริงด้วย Gemini (ต้องมี GOOGLE_API_KEY ใน .env)
python main.py --condition full --population 30 --days 40

# รันครบทั้งสามเงื่อนไขต่อกัน แล้ววาดกราฟ
python main.py --all --population 20 --days 30
python plot_results.py
หน้าเว็บนี้จำลองการตัดสินใจด้วย กฎ heuristic เดียวกับ MockDecisionAgent เพื่อให้เล่นได้ทันทีในเบราว์เซอร์โดยไม่ต้องเรียก API — ตรรกะของโรค การสัมผัส และลำดับขั้นในหนึ่งวัน ตรงกับโค้ด Python ทุกประการ ต่างกันเพียงตัวสุ่มคนละชุด ผลลัพธ์จึงไม่ตรงกันแบบตัวต่อตัวกับการรันจริง
