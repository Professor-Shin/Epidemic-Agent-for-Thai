1.1 SEIR และสมการ final size

SEIR คือแบบจำลองโรคระบาดแบบ compartment ประชากรถูกแบ่งเป็นสี่ถัง

dS/dt = −β·SI/N   ·   dE/dt = β·SI/N − σE   ·   dI/dt = σE − γI   ·   dR/dt = γI

E คือ “ติดแล้วแต่ยังไม่แพร่” (ระยะฟักตัว) ซึ่งสำคัญกับโรคทางเดินหายใจ ถ้าใช้ SIR เฉย ๆ จะได้ยอดพีคที่มาเร็วเกินจริง

ค่าในโปรเจกต์นี้ (config/base.yaml) คือ β₀ = 0.2 ต่อวัน, latent 4 วัน (σ = 0.25), infectious 10 วัน (γ = 0.1) ทำให้

R₀ = β₀/γ = 0.2 × 10 = 2.0

จาก Kermack–McKendrick final size equation สัดส่วนคนที่ติดเชื้อตลอดการระบาดหาได้จาก

z = 1 − e−R₀z แก้ที่ R₀ = 2 ได้ z = 0.7968 — แต่สูตรนี้สมมติว่าเริ่มจากทุกคนยังไม่ติด

นี่คือคำตอบเชิงวิเคราะห์ที่ รู้ล่วงหน้าโดยไม่ต้องรันอะไรเลย และเป็นเหตุผลที่เงื่อนไข A มีอยู่ แต่ต้องใช้สูตรให้ตรงกับแบบจำลอง เพราะเราหว่าน E = I = 0.002 ไว้ตั้งแต่วันแรก ดังนั้น S₀/N = 0.996 ไม่ใช่ 1 สูตรที่ถูกคือ s = s₀·exp(−R₀(1−s)) ซึ่งให้ 0.798176 ไม่ใช่ 0.7968

โค้ดรันได้ 0.795010 ที่ 180 วัน ซึ่งยังไม่ใช่ final size เพราะเหลือ I = 0.38% เมื่อรันต่อค่าลู่เข้าที่ 0.798176 ตั้งแต่วันที่ 365 และที่ 730 วันตรงกับสูตรถึง 3.8 × 10⁻¹³ — คือตรงกันในระดับความแม่นของเลขทศนิยมลอยตัว ไม่ใช่แค่ "ใกล้เคียง" เครื่องยนต์ถูก ตรวจซ้ำได้ด้วย scripts/analysis/seir_validation.py

def final_size(R0):
    """Final attack rate z from z = 1 - exp(-R0 z) for a fully susceptible population."""
    if R0 <= 1: return 0.0
    return brentq(lambda z: z - (1 - np.exp(-R0 * z)), 1e-9, 1.0)

ทำไมต้องหารด้วย employment_rate — ตัวเลข Prem คือค่าเฉลี่ยของ ผู้ใหญ่ทุกคน รวมคนที่ไม่ได้ทำงาน แต่เราอยากรู้ว่า “คนที่ไปทำงานจริงวันนั้น สัมผัสกี่คน” ถ้าในประชากร 67% ทำงาน แล้วค่าเฉลี่ยรวมคือ 3.86 คนที่ไปทำงานจริงต้องสัมผัส 3.86/0.67 = 5.76 ไม่หารจะประเมินการสัมผัสที่ทำงานต่ำไป 33%

ทำไม work_onsite ต้องบวก others ด้วย — วันที่ไปทำงานคุณไม่ได้เจอแค่เพื่อนร่วมงาน คุณขึ้นรถเมล์ ซื้อข้าวกลางวัน f_work_other = 0.3 คือสมมติว่า 30% ของการสัมผัส “อื่น ๆ” เกิดในวันทำงาน

ทำไม visit_family ต้องบวก home เข้าไป — ไปเยี่ยมญาติคือการเข้าไปในอีกครัวเรือนหนึ่ง f_visit_home = 0.5 คือสมมติว่าได้การสัมผัสในบ้านนั้นครึ่งหนึ่งของบ้านตัวเอง นี่คือเหตุผลว่าทำไม visit_family (4.03) ถึงอันตรายกว่า essential_errand (2.57) ทั้งที่ออกไปข้างนอกเหมือนกัน

self.base_out = sum(baseline_mix[a] * c_out[a] for a in actions)   # = 4.835
self.w_home   = self.home / (self.home + self.base_out)            # = 0.507

def q_out(self, shares):
    return sum(shares[a] * c_out[a] for a in actions) / self.base_out

def beta_eff(self, beta0, q_out, q_policy=1.0):
    return beta0 * (self.w_home + (1 - self.w_home) * q_out * q_policy)

ทำไมต้องแยก w_home ออกมา — ถ้าไม่มีพจน์นี้ stay_home จะแปลว่า c_out = 0 แปลว่า β = 0 แปลว่า อยู่บ้านแล้วติดเชื้อไม่ได้ ซึ่งผิดอย่างร้ายแรง ในความจริง 50.7% ของการสัมผัสทั้งหมดในวันปกติเกิดที่บ้าน และการอยู่บ้านไม่ได้ลบมันทิ้ง

ผลที่ตามมา: แม้ทุกคนอยู่บ้านหมด β ก็ลดได้แค่ครึ่งเดียว (β = 0.2 × 0.507 = 0.101 → R₀ = 1.01) ซึ่งอยู่ขอบ threshold พอดี นี่คือ “เพดาน” ที่อธิบายว่าทำไมแม้ typhoon8b ที่อยู่บ้าน 39% ของเวลาก็ยังหยุดการระบาดไม่ได้

def parse_choice(text, allowed, key="action"):
    m = JSON_RE.search(text or "")              # 1. หา JSON ในข้อความ
    if not m: return None, None, "no_json"
    try: obj = json.loads(m.group(0))
    except json.JSONDecodeError: return None, None, "bad_json"
    choice = str(obj.get(key, "")).strip().lower()
    if choice not in allowed:                   # 2. ต้องอยู่ในรายการที่อนุญาต
        return None, obj.get("reason"), f"not_allowed:{choice[:30]}"
    return choice, obj.get("reason"), None
