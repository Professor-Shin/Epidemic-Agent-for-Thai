## 2. บทนำ (Introduction) — ~1.5 หน้า

มาจาก "ที่มาและความสำคัญ" ของรายงาน #1 เขียนใหม่ให้เป็นร้อยแก้ว ไม่ใช่ bullet

**โครงเรื่อง 4 ย่อหน้า**

1. แบบจำลองโรคระบาดเชิงกลไกไม่ค่อยจัดการพฤติกรรมมนุษย์อย่างจริงจัง งานที่ ground กับข้อมูลจริงมักป้อนพฤติกรรม
   แบบ exogenous (mobility time series) ส่วนที่ทำ endogenous มีน้อย → เกิด bias ใน long-term projection
   (ประเด็นของ Williams et al.)
2. LLM เปิดทางให้ทำ endogenous behaviour ได้โดยไม่ต้องบังคับกฎการตัดสินใจ แต่ก็เปิดปัญหาใหม่ว่า
   **พฤติกรรมที่เห็นเป็นของใคร** — ของมนุษย์ที่จำลอง หรือของ behavioral prior ที่ติดมากับโมเดล (ประเด็นของ Ferencz et al.)
3. ปัญหานี้แหลมคมเป็นพิเศษนอกบริบทตะวันตก เพราะ LLM ส่วนใหญ่ฝึกด้วยข้อมูลภาษาอังกฤษ
   ทางแก้ที่ดูเป็นธรรมชาติคือใช้โมเดลที่จูนด้วยภาษาท้องถิ่น — **แต่ยังไม่มีใครทดสอบว่าวิธีนี้ได้ผลจริงหรือไม่**
4. คำถามวิจัยและสิ่งที่งานนี้ทำ (ย่อหน้าสุดท้ายควรระบุ contribution เป็นข้อ ๆ)

**คำถามวิจัย** ควรเขียนให้ชัดเป็น 3 ข้อ

- RQ1 การจูนภาษาไทยเปลี่ยนพฤติกรรมของ LLM agent ในแบบจำลองโรคระบาดหรือไม่ และเปลี่ยนไปในทิศใด
- RQ2 ถ้าเปลี่ยน กลไกคืออะไร
- RQ3 ผู้นำ LLM ที่ตัดสินใจรายสัปดาห์ตอบสนองต่อสถานการณ์ระบาดหรือไม่

**Contributions** ที่เคลมได้จริง

1. การออกแบบ 2×2 (ตระกูลโมเดล × การจูนภาษา) ซึ่งเป็นการแยกสองปัจจัยนี้ออกจากกันเป็นครั้งแรกในงาน GABM ระบาดวิทยา
2. หลักฐานว่าผลของการจูนภาษา **กลับเครื่องหมาย**ระหว่างตระกูล พร้อมกลไกที่ตรวจสอบได้จากข้อความ
3. หลักฐานเชิงปริมาณว่าผู้นำ LLM แยกขาดระหว่างการให้เหตุผลกับการกระทำ
4. ชุดการทดสอบความคงทนที่งาน GABM ส่วนใหญ่ไม่ทำ (สลับลำดับตัวเลือกใน prompt)

## 3. งานที่เกี่ยวข้อง (Related Work) — ~2 หน้า

มาจากรายงาน #1 ทั้งหมด **แต่ต้องเขียนใหม่** จากรูปแบบ "สรุปทีละงาน" เป็นร้อยแก้วที่เล่าว่าสามงานนี้ต่อกันอย่างไร

### 3.1 GABM กับพฤติกรรมประชาชน — Williams et al. (2023)

- เสนอ GABM ที่ใช้ generative agents เป็น proxy ของมนุษย์ โดยไม่บังคับกฎการตัดสินใจ
- 3 เงื่อนไข: base / self-health feedback / full feedback · Python + Mesa · gpt-3.5-turbo-0301
- n = 100 และ 1,000 · contact rate 5, infectivity 0.1 → R₀ ≈ 3 · decision log ~67,000 observations
- ใช้ชื่อไวรัสและเมืองสมมติเพื่อเลี่ยง bias ที่ฝังใน LLM
- เทียบกับโลกจริงเชิงคุณภาพเท่านั้น ไม่ fit กับ epidemic curve ของประเทศใด
- **ช่องว่าง:** การตัดสินใจเป็นทวิภาค (อยู่บ้าน/ออกไปทำงาน) และใช้โมเดลเดียว

### 3.2 พฤติกรรมเป็นของใคร — Ferencz et al. (2026) Epi-LLM

**งานที่ใกล้เคียงกับคำถามของเราที่สุด ต้องอภิปรายละเอียดที่สุด**

- ตั้งคำถามตรงว่าพฤติกรรมที่ LLM แสดงเป็นการจำลองมนุษย์ หรือเป็น behavioral prior ของโมเดล
- แยกปัญหาเป็น internal validity (เปลี่ยนโมเดลแล้วผลเปลี่ยน → ข้อสรุปเชิงนโยบายไร้ความหมาย)
  กับ cultural validity
- **สมมติฐานที่งานนี้ตั้งใจทดสอบ: "บอก LLM ว่า agent เป็นคนประเทศ X แล้วจะได้พฤติกรรมแบบประเทศ X"**
- Starsim + SEIR 15 วัน · contact network จาก AUIB epigame (log-normal fit)
- การตัดสินใจกักตัวมี economic trade-off เป็นตัวเลขจริง (5 แต้มถ้ากักตัว เทียบ 10–15 แต้มถ้าออกไป)
- health beliefs 4 มิติจาก Health Belief Model ดึงจาก survey มนุษย์จริง
- 4 โมเดล 70B–120B ครอบคลุม dense transformer และ MoE เพื่อแยกผลของสถาปัตยกรรมจากขนาด
- geographic label experiment: China / Iraq / Kenya / UK
- **ช่องว่าง:** ทดสอบด้วย *ป้ายกำกับประเทศ* ซึ่งเป็นการแทรกแซงที่อ่อนที่สุดเท่าที่ทำได้
  ยังไม่มีใครทดสอบการแทรกแซงที่แรงกว่านั้นคือ **การจูนน้ำหนักโมเดลด้วยภาษาท้องถิ่น**
  → **นี่คือช่องว่างที่งานนี้เข้าไปเติม**

### 3.3 ผู้นำ LLM — Aoki & Ghaffarzadegan (2026)

- agent สวมบทบาทนายกเทศมนตรีใน SEIR environment · ประชากร 1 ล้าน β₀ = 0.2 latent 4 infectious 10
  **(งานนี้ใช้พารามิเตอร์โรคชุดเดียวกัน ต้องระบุให้ชัดว่ารับมาจากที่นี่)**
- β = β₀ · b · g · ε โดย b = พฤติกรรมสมัครใจ, g = มาตรการรัฐ, α = 0.8
- World 1 นโยบายเป็นตัวแปรเดียว · World 2 เพิ่ม b = 1/(1 + k·C₍t−1₎) **(เงื่อนไข B ของเรารับสูตรนี้มา)**
- เลือกระดับปิดกิจการ 0–100% ทุก 7 วัน จำลอง 365 วัน · GPT-5 nano · ~520 API calls ต่อ ensemble run
- 2×4 design · knowledge intervention คือข้อความ ~200 คำอธิบาย feedback loop
- ผล: knowledge ลดเคส ⅓ · ensemble เดี่ยว ๆ **ทำให้แย่ลง ⅓** · ensemble + knowledge ลด 50%
- **Regression: นโยบายสัปดาห์ก่อนเป็นตัวทำนายที่แรงที่สุด (p<0.001) → policy inertia สูงมาก**
  **(ผลผู้นำของเราคือเคสสุดขั้วของข้อนี้ — ต้องผูกกลับมาตรงนี้ใน discussion)**
- ความรุนแรงที่ระลึกได้มี coefficient ติดลบ → adaptation/normalization
- **ช่องว่าง:** ประชาชนไม่ใช่ LLM agent (เป็นสมการ) จึงวัดไม่ได้ว่าประชาชนกับผู้นำมีส่วนในผลคนละเท่าไร

## 4. วิธีการ (Methods) — ~3 หน้า

ส่วนที่ 1 ของรายงาน #3 ใช้ได้เกือบหมด **แต่ต้องอัปเดตเลขจาก 30 วัน/2 โมเดล เป็น 180 วัน/5 โมเดล**

### 4.1 สถาปัตยกรรม
แผนภาพ feedback loop จากรายงาน #3 ใช้ได้เลย

### 4.2 กลไกโรค (SEIR)
`solve_ivp` รายวัน · ตรวจอนุรักษ์ S+E+I+R = N · N = 1,000,000 · β₀ = 0.2 · latent 4 · infectious 10 → **R₀ = 2.0**

### 4.3 การแปลง action → การสัมผัส ★หัวใจของวิธี
โค้ดจริงจาก `gabm/contacts.py` · เมทริกซ์ Prem et al. (2021) ไทย `adult_20_64` (home 4.98, work 3.857, others 5.147)

| action | c_out | relative contact |
|---|---|---|
| work_onsite | 7.356 | 1.257 |
| visit_family | 4.034 | 0.918 |
| essential_errand | 2.573 | 0.770 |
| stay_home | 0 | 0.507 |

ต้องเน้นว่า `stay_home` ≠ การสัมผัสเป็นศูนย์ เพราะเก็บการสัมผัสในครัวเรือนไว้ — ต่างจาก action ทวิภาคของงานที่ 1 และ 3
และต้องระบุว่า `relative = (1 − w_home)·(c_out/base_out) + w_home` โดย `w_home = 0.507`, `base_out = 4.835`

### 4.4 ประชากรสังเคราะห์และ persona
40 agents 6 กลุ่มอาชีพ · ตัวอย่าง prompt เต็มควรใส่เป็นกล่องในหน้านี้ (ไม่ใช่ภาคผนวก) เพราะผู้อ่านต้องเห็นว่า
`Can work from home` และ `Household size` อยู่ตรงไหน

### 4.5 เงื่อนไข A–D
ตารางจากรายงาน #3 ใช้ได้ · ต้องระบุ **d_gate** ว่าเงื่อนไข D รันก็ต่อเมื่อ C ครบ 3 seeds และ fallback < 5%

### 4.6 แผงโมเดล 2×2
ตารางโมเดล + เหตุผลว่าทำไม seallm7b เป็นตัวควบคุมที่เหมาะ (จูนภูมิภาคแต่ไม่เจาะจงไทย)

## 6. ผลการทดลอง (Results) — ~4 หน้า

**ลำดับการเล่าควรเป็น: ยืนยันว่าเครื่องมือถูกต้องก่อน → ผลหลัก → กลไก → ความคงทน**

### 6.1 การตรวจสอบแกน SEIR
A = 0.795 เทียบ final size เชิงวิเคราะห์ของ R₀ = 2.0 = 0.797 · B = 0.469

### 6.2 ความน่าเชื่อถือของชั้น LLM
schema ถูก 99.85–100% ตั้งแต่ครั้งแรก · **fallback 0% ใน 216,000 การตัดสินใจ** · ไม่มีรันไหนขาด

### 6.3 ผลหลัก — 2×2 ★ (RQ1)
**รูปที่ 1** = `outputs/figures/04_2x2_localisation.png` (ทำแล้ว)

| | base | Thai-tuned | ผลของการจูน |
|---|---|---|---|
| Llama 3.1 8B (C) | 0.819 | 0.640 | **−0.179** |
| Qwen 2.5 7B (C) | 0.830 | 0.858 | **+0.028** |
| Llama 3.1 8B (D) | 0.601 | 0.268 | **−0.332** |
| Qwen 2.5 7B (D) | 0.666 | 0.723 | **+0.057** |

seallm7b C 0.845 / D 0.693 → อยู่กลุ่มเดียวกับโมเดลฐาน **การจูนภูมิภาคอย่างเดียวไม่พอ** ซึ่งสอดคล้องกับ Ferencz et al.

ต้องระบุว่า SD ข้าม seed (0.001–0.030) ต่ำเพราะ N = 1 ล้าน ไม่ใช่เพราะ LLM เสถียร

### 6.4 กลไก — การวิเคราะห์เหตุผล ★ (RQ2)
**รูปที่ 2** = `outputs/figures/04_reason_diversity.png` (ทำแล้ว)

| โมเดล | เหตุผลไม่ซ้ำ | กรอบ "รายได้" |
|---|---|---|
| llama8b | 76.5% | 54% |
| typhoon8b | 65.2% | **19%** |
| seallm7b | 64.8% | 59% |
| qwen7b | **19.0%** | 56% |
| openthaigpt7b | **17.1%** | **65%** |

สองข้อค้นพบ: (ก) ตระกูล Qwen เกิด **reason collapse** (ข) การจูนไทยลดกรอบรายได้ในตระกูล Llama
แต่เพิ่มในตระกูล Qwen **ตรงกับเครื่องหมายของ effect ทั้งสองตระกูลพอดี**

ข้อสังเกตที่ไม่คาด: ไม่มีโมเดลใดตอบเป็นภาษาไทยเลย เพราะ prompt เป็นอังกฤษ →
**การจูนภาษาส่งผลที่เนื้อหาการตัดสินใจ ไม่ใช่ที่ภาษาของเอาต์พุต**

### 6.5 เงื่อนไข D — ผู้นำ ★ (RQ3)
D ลด attack rate ทุกโมเดล (−0.135 ถึง −0.371) **แต่** `strict` ถูกเลือก **4 ครั้งจาก 390**

หลักฐานชี้ขาดสองข้อ:
- รันเดียวที่ยกระดับ (llama8b seed 2) มี peak **ต่ำสุด**ในสาม seeds ของตัวเอง (528 เทียบ 625 และ 644)
- openthaigpt7b เห็น 986 เคส/แสน/วัน แล้วยังเลือก `limited`

แต่ `reason` รายงานสถานการณ์ถูกต้องทุกสัปดาห์ → **dissociation ระหว่างการให้เหตุผลกับการกระทำ**

### 6.6 ความสมเหตุสมผล (Face validity)
ตารางอาชีพ (office อยู่บ้านมากสุด, trade/agri น้อยสุด — ถูกทิศทุกโมเดล) ·
ตารางการตอบสนองต่ออาการป่วย (ทุกโมเดลเพิ่มการอยู่บ้าน +0.048 ถึง +0.326)
ต้องรายงานจุดอ่อนด้วย: openthaigpt7b ไปทำงาน 66.8% ขณะมีไข้

### 6.7 ความคงทนต่อลำดับใน prompt
ตารางเต็ม 15 แถว · ข้อสรุป: **เครื่องหมายของ effect คงที่ทั้งสามลำดับ** แต่สัดส่วน action รายตัวแกว่งหนัก
(qwen7b `essential_errand` 0.000–0.681)

### 6.8 Sensitivity **[รอผล array 416032 และ 416120]**
เงื่อนไข B: `w_home_scale` 0.176 เทียบ `f_visit` 0.007 (ต่างกัน 25 เท่า)
เงื่อนไข C: llama8b ครบ 4 แกน · อีก 4 โมเดลเฉพาะ `wfh_scale`
**ต้องเขียนตรง ๆ ว่าไม่สมมาตรเพราะงบ GPU ไม่ใช่เพราะออกแบบมาแบบนั้น**

### 6.9 ความไวต่อ baseline_mix **[รอผล]**
ทดสอบว่าข้อสังเกต "C ระบาดหนักกว่า A" เป็นผลการทดลองหรือเป็น artefact ของ assumption

### 6.10 ขอบฟ้า 365 วัน **[รอผล array 416035]**
ตอบว่าการจูนไทย *ลด* หรือเพียง *ยืด* การระบาด

## 7. อภิปราย (Discussion) — ~2 หน้า ★ส่วนที่ทำคะแนนมากที่สุด

**อย่าเล่าผลซ้ำ ให้ผูกผลเข้ากับวรรณกรรมทั้งสามชิ้น**

### 7.1 ต่อ Ferencz et al. — ป้ายกำกับประเทศไม่พอ และการจูนภาษาก็ไม่พอเหมือนกัน
Ferencz et al. ทดสอบว่าป้ายกำกับประเทศให้พฤติกรรมตามประเทศหรือไม่ งานนี้ทดสอบการแทรกแซงที่**แรงกว่ามาก**
คือการจูนน้ำหนักด้วยภาษาท้องถิ่น และพบว่า **ยังไม่พอ** เพราะผลกลับเครื่องหมายตามโมเดลฐาน
→ ขยายข้อสรุปของ Ferencz et al. จาก "ป้ายกำกับไม่พอ" เป็น **"การแทรกแซงเชิงวัฒนธรรมที่ระดับโมเดลก็ยังไม่รับประกันความถูกต้องเชิงวัฒนธรรม"**
และ seallm7b (จูนภูมิภาค) ที่อยู่กลุ่มเดียวกับโมเดลฐานเป็นหลักฐานสนับสนุนเพิ่ม

### 7.2 ต่อ Aoki & Ghaffarzadegan — policy inertia ในรูปแบบสุดขั้ว
เขาพบว่านโยบายสัปดาห์ก่อนเป็นตัวทำนายที่แรงที่สุด (p<0.001) งานนี้พบกรณีที่ inertia สมบูรณ์แบบ
คือไม่เปลี่ยนเลย 25 จาก 26 สัปดาห์ แม้เคสขึ้นถึง 986/แสน/วัน

ต่างกันตรงที่ **ประชาชนของเราเป็น LLM ด้วย** จึงแยกได้ว่าความต่างของผลในเงื่อนไข D
มาจากประชาชน ไม่ใช่จากผู้นำ — เป็นสิ่งที่งานของเขาแยกไม่ได้เพราะประชาชนเป็นสมการ

ข้อเสนอที่ต่อยอดได้: knowledge intervention ของเขา (~200 คำอธิบาย feedback loop) น่าจะเป็นทางแก้ dissociation ที่เราเจอ

### 7.3 ต่อ Williams et al. — พฤติกรรม endogenous ไม่ได้แปลว่าการระบาดเบาลงเสมอ
Williams et al. แสดงว่าพฤติกรรมที่ตอบสนองทำให้เส้นการระบาดเปลี่ยน งานนี้พบว่า **4 ใน 5 โมเดลทำให้แย่ลงกว่า baseline**
(q̄_out > 1) ซึ่งเป็นผลที่ต้องอภิปรายอย่างระมัดระวัง เพราะขึ้นกับ `baseline_mix` **[โยงผล 6.9]**

### 7.4 นัยเชิงปฏิบัติสำหรับคนที่จะทำ GABM นอกบริบทตะวันตก
3–4 ข้อเสนอที่ใช้ได้จริง เช่น ต้องทดสอบหลายโมเดลเสมอ · ต้องตรวจ position bias · ต้องดู reason diversity
ไม่ใช่ดูแค่ผลลัพธ์รวม

## 8. ข้อจำกัด (Limitations) — ~1 หน้า

เรียงตามความร้ายแรง ไม่ใช่ตามลำดับที่นึกออก

1. ผู้นำไม่แปลงการอ่านเป็นการกระทำ → เงื่อนไข D เทียบเท่านโยบายคงที่
2. `baseline_mix` เป็น assumption ที่ไม่มีแหล่งอ้างอิง และผล "C > A" ขึ้นกับมัน **[ลดความร้ายแรงได้ถ้า 6.9 ออกมาดี]**
3. สัดส่วน action รายตัวไม่คงทนต่อลำดับใน prompt
4. 180 วันไม่พอสำหรับ typhoon8b **[ลดความร้ายแรงได้ถ้า 6.10 ออกมา]**
5. `household_size` ไม่เข้าแบบจำลอง เป็นแค่ข้อความใน prompt
6. sensitivity ไม่สมมาตรระหว่างโมเดล และเป็น one-at-a-time จับ interaction ไม่ได้
7. 18 จาก 28 พารามิเตอร์มีสถานะ `assumption`
8. 3 seeds · 40 agents แทนประชากร 1 ล้าน · 4-bit quantization
9. เป็น scenario study ไม่ใช่ forecast ที่ calibrate
